# Coloca aquí los PDFs de cada catálogo

Cualquier archivo `.pdf` que pongas en esta carpeta aparecerá automáticamente
en la web tras volver a desplegar (o tras correr `npm run build` en local).

Ejemplos:
- `catalogo-retro.pdf`
- `catalogo-mundial.pdf`
- `catalogo-chandales.pdf`

El nombre del fichero (sin guiones bajos) se usa como título en la web.
